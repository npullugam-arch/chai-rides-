# CHAI RIDES

Astro website for CHAI RIDES, including the original interactive 3D café experience, a server-rendered franchise website, and a Supabase-backed franchise CMS.

## Commands

```powershell
npm install
npm run db:test
npm run db:setup
npm run dev
npm run build
```

See [CHAI_RIDES_SETUP.md](./CHAI_RIDES_SETUP.md) for Supabase Auth, Storage, RLS and Vercel environment setup.
